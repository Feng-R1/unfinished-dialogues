未竟 · 与先贤对话 / Windows 免安装版

1. 将整个压缩包解压到一个文件夹（不要直接在压缩包里双击）。
2. 双击“未竟.exe”。无需安装 Node.js、npm 或下载依赖。
3. 首次可选择演示模式，也可填入自己的模型 API 密钥。
4. 点击“打开未竟”，浏览器自动打开。关闭启动器会停止本机服务。

支持 Windows 10/11 x64。使用系统自带 .NET Framework 4.8 和默认浏览器。
本版本未购买代码签名证书，系统可能提示未知发布者。
请只使用项目官方 GitHub Releases 下载，并核对同页 SHA256SUMS.txt。

模型密钥不会内置在运行包里。真实模型按你使用的服务商规则计费。
启动器使用 Windows 当前用户加密保护保存密钥，文件位于：
%LOCALAPPDATA%\UnfinishedDialogues\settings.json
其余设置及模型密钥不会上传到 GitHub。模型对话会发送至你填写的服务商。

页面仅监听 http://127.0.0.1:3210 ，不开放局域网访问。
若 3210 端口被其他程序占用，会明确报错，不会自动换端口导致历史消失。
双击多个副本时只会保留一个启动器，请回到已打开的窗口。

历史对话保存在默认浏览器对应地址的 IndexedDB 中。
升级时解压到新文件夹、使用相同浏览器和地址即可继续读取；
更换浏览器、清除网站数据或切换地址会影响历史记录。
演示内容为预写示例，不能理解任意追问。真实模式需要联网。
